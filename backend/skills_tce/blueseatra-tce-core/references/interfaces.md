# Interfaces sans double compte

Chaque dépendance conserve son ouvrage parent, son scénario, sa zone et un lot
responsable. Créer un candidat conditionnel ; ne pas déclarer la faisabilité.

| Interface | Vérifier |
|---|---|
| Dépose / ouvrages | consignation, obturation, support, déchets et reprises |
| Structure / réseaux | réservations, percements, charges, scellements |
| Cloisons / réseaux | passages avant fermeture, renforts, boîtes, trappes, essais |
| Isolation / enveloppe | continuité, étanchéité à l'air, condensation, ventilation |
| Sol / douche | niveaux finis, support, évacuation, étanchéité et seuils |
| Sanitaires / électricité | alimentation chauffe-eau et équipements, protections |
| VMC / menuiseries / toiture | air neuf, rejet autorisé, traversées, accès entretien |
| Cuisine / réseaux | pose mobilier vs évier, découpes, eau, courant, vidages |
| Chauffage / extérieur | condensats, support, acoustique, alimentation |
| Tous lots / réception | essais, nettoyage, documents et réserves |

Protections, évacuation et nettoyage communs ne sont pas une somme de forfaits par lot.
Le SaaS consolide avec une clé zone + service + scénario ; il conserve toutes les
preuves client même lorsqu'elles alimentent une seule prestation.
